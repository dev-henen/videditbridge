API keys

To edit in VideditBridge's own chat, the app needs an API key from at least one AI company. A key is like a password that lets the app use your account with that company. Here is how to get one and add it.

Default

Claude (Anthropic)

Opus, Sonnet and Haiku. The default, and the one the editor was built around.

 Optional

ChatGPT (OpenAI)

GPT models from OpenAI, with the same editing tools.

 Optional

Gemini (Google)

Gemini models; Google AI Studio has a free tier to start with.
An API key is not your chat subscription.

Claude Pro, ChatGPT Plus and Gemini Advanced are for the companies' own apps. API use is paid separately, by what you use. If you already pay for Claude and would rather not set up an API key, use VideditBridge from the Claude app instead.

Where to add a key

Open Settings (the menu at the top left, or Ctrl + ,) and go to AI models. Each company has a row with How to get one (this page) and Add key.

Claude (Anthropic)

  1. Sign in to the Anthropic Console. Go to console.anthropic.com and sign in or create an account. This is separate from claude.ai, though you can use the same email.
  2. Add credit. Under Billing, add a payment method and buy some credit. The API needs credit before it answers; a few dollars goes a long way for trying things out.
  3. Create a key. Open API keys and press Create key. Name it something you will recognize, like "VideditBridge".
  4. Copy it. The key starts with sk-ant-. It is shown only once, so copy it now.
  5. Add it to VideditBridge. In Settings, AI models, press Add key on the Claude row, paste, and press Save (or Enter).

ChatGPT (OpenAI)

  1. Sign in to the OpenAI platform. Go to platform.openai.com. Your ChatGPT login works here too, but API billing is separate from a ChatGPT plan.
  2. Set up billing. In the settings, under Billing, add a payment method or credit.
  3. Create a key. Open API keys and press Create new secret key. Give it a name and create it.
  4. Copy it. The key starts with sk- and is shown only once.
  5. Add it to VideditBridge. In Settings, AI models, press Add key on the ChatGPT row, paste and save.

Gemini (Google)

  1. Open Google AI Studio. Go to aistudio.google.com and sign in with a Google account. A personal account works.
  2. Get a key. Press Get API key, then Create API key. If it asks for a Google Cloud project, let it make one.
  3. Copy it. The key starts with AIza.
  4. Add it to VideditBridge. In Settings, AI models, press Add key on the Gemini row, paste and save.
The free tier has limits.

Without billing, Gemini allows only so much per minute and per day. A long edit can reach the limit; the chat then says so and when to try again. Turning on billing in Google AI Studio raises the limits.

Choosing the model

The model picker under the chat box lists only the models whose key you added. New conversations start with the Default model from Settings, and each conversation keeps the model it uses. You can switch at any time; the conversation carries on.

ModelGood for
Claude Opus, GPT Astra, Gemini CarbonFull edits from raw footage: the most capable, and the slowest and priciest.
Claude Sonnet, GPT Sol, Gemini HydrogenMost everyday edits: fast and capable.
Claude Haiku, GPT Luna, Gemini Flash-LiteSmall changes ("make the title red"): the fastest and cheapest.

Keeping keys safe

  • Keys are kept on this computer only, in the system keychain: Windows Credential Manager, the macOS Keychain, or the keyring on Linux. Each key is sent only to its own company.
  • To change a key, press Change; to delete it, press Remove. You can also delete a key in the company's console, which stops it working everywhere.
  • Never share a key or paste it into a chat. If one leaks, delete it in the company's console and make a new one.
For developers: environment variables

A key in ANTHROPIC_API_KEY, OPENAI_API_KEY or GEMINI_API_KEY (or GOOGLE_API_KEY) is used instead of a saved one, and Settings says so.

The companies' websites change their menus now and then; if a step looks different, look for "API keys" in the console's menu.
