Use the Claude app

If you use the Claude desktop app, you can edit with VideditBridge from there, with your own Claude account. VideditBridge needs no API key for this, and the previews play right in Claude's chat.

How it works

VideditBridge adds itself to the Claude app as a connector (an MCP server, the standard way apps give Claude new tools). Claude then has the same editing tools as VideditBridge's own chat, and works on your VideditBridge projects.

Connect it

  1. Install the Claude desktop app. Download it from claude.ai/download and sign in.
  2. Open VideditBridge's Connections. In VideditBridge, open Settings and go to Connections. The Claude app row says Not connected.
  3. Press Connect. VideditBridge adds itself to the Claude app's settings file. Nothing else in that file changes, and the previous file is kept as a backup.
  4. Restart the Claude app. Quit it completely (on Windows, right-click its icon by the clock and choose Quit; on a Mac, Cmd + Q), then open it again. Closing the window is not enough.
  5. Ask Claude. In a new chat, for example: "List my VideditBridge projects", then "Open City Lights Teaser and make the title bigger, then show me a preview." Claude asks before using a tool the first time; allow it.

What you will see

  • Previews in the chat. When Claude renders a preview, a frame or a contact sheet, it plays or shows inside Claude's reply.
  • Your projects stay in VideditBridge. Claude works on the same projects. If VideditBridge is open, the edits go through it (and are saved there) without opening a tab; if it is closed, Claude edits the project files directly.
  • Undo still works. Open the project in VideditBridge to see every change in History and undo any of them.

Claude Code, Gemini CLI and other tools

Developers can use VideditBridge from command-line AI tools too. In Settings, Connections:

ToolHow
Claude CodePress Copy command on the Claude Code row and run it once in a terminal. It looks like this:
Gemini CLIPress Connect on the Gemini CLI row, then start a new Gemini CLI session. (This is Google's terminal tool, not the Gemini app.)
Other MCP toolsPress Copy command on Other apps and add it as a stdio MCP server in the tool's settings.
claude mcp add --scope user videditbridge -- node "/path/to/videditbridge/dist/mcp/main.js" --projects-dir "/path/to/projects"

Terminal tools cannot show video, so VideditBridge opens the project itself as the preview window. Its chat is hidden there, because the conversation happens in the terminal; Use the chat here brings it back.

The ChatGPT and Gemini apps

Not yet. Their connectors are called from OpenAI's and Google's servers, so they would need your computer reachable from the internet. Until there is a safe and simple way, use them through an API key in VideditBridge's own chat.

Disconnect

Press Disconnect on the Claude app row, then restart the Claude app. VideditBridge takes only its own entry out of the Claude app's settings.

Not showing up in Claude?

Make sure you quit the Claude app completely, and that the row in VideditBridge says Connected (if it says Update, press it). More in Troubleshooting.
