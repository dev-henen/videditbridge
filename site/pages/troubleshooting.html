Troubleshooting

When something goes wrong, the chat says what happened in one sentence and what to do. Here is what each message means, and fixes for other common problems.

Messages in the chat

The chat saysWhat to do
... did not accept the API keyThe key is wrong, was deleted, or belongs to another account. In Settings, AI models, press Change and paste a fresh key. See API keys.
... says this key has hit its usage limitYou used the key's allowance for now, or ran out of credit. Wait the time it says and try again, add credit in the company's console, or pick a model from another company. Google's free tier has low per-minute limits.
... is not available with this keyYour account cannot use that model yet. Pick another one in the model picker under the chat box.
... is busy right now / had a problem on its sideThe company's service is overloaded or down for a moment. Try again shortly.
Could not reach ...No internet connection, or something blocks the app (a firewall or VPN). Check the connection and try again.
This conversation has grown too longLong conversations fill the model's memory. Start a new conversation with the pencil icon above the chat; the project is not affected.

The chat is off: "Add an API key to start editing"

No API key is set yet. Press Open Settings and add one (how), or use VideditBridge from the Claude app.

If you have a key but a model is missing from the picker, the picker lists only models whose company has a key. Add that company's key, or pick from the list.

The Claude app does not show VideditBridge

  • Quit the Claude app completely and open it again: it reads its connectors only when it starts. On Windows, right-click its icon by the clock and choose Quit.
  • Check the row in VideditBridge. Settings, Connections, Claude app should say Connected. If it says Update, press it (VideditBridge moved or was renamed), then restart the Claude app.
  • Look in the right place. Connectors on your computer show in the Claude app's settings (under Developer) and in the tools menu of a chat.
  • Still nothing? Press Disconnect, then Connect again, and restart the Claude app.

The preview is slow or looks wrong

  • In Settings, Rendering, press Test again: VideditBridge measures your graphics card and processor and picks the faster one.
  • If the picture looks wrong, set Renderer to FFmpeg only and report it (below) so it can be fixed.
  • Large videos preview from smaller copies made in the background; the first preview of a new file takes longer.

Where are my files?

Settings, Folders lists the projects folder, the downloaded models, fonts and the cache, each with an Open button. Each project is a folder with your media, the edit and its conversations.

Report a problem

Open an issue on GitHub with what you did, what you expected and what happened. A screenshot helps. Never include your API keys.
