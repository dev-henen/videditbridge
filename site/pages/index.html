Edit videos by asking.

VideditBridge is a video editor for Windows, macOS and Linux that you use by talking to an AI. Say what you want, like "cut this into a 30 second trailer", and watch Claude, ChatGPT or Gemini make the edits in front of you.

Two ways to edit

In VideditBridge

Ask in the app's own chat

Add an API key from Anthropic (Claude), OpenAI (ChatGPT) or Google (Gemini) in Settings, then ask in the chat on the right.

 In the Claude app

Ask from the Claude app

Connect VideditBridge to the Claude desktop app and edit with your Claude account. No API key needed; previews play in Claude's chat.

Your first edit

  1. Install VideditBridge. Get the installer for Windows, macOS or Linux from Download; the page shows what to do the first time you open it.
  2. Open VideditBridge and make a project. On the Projects page, type a name, pick a shape (16:9 for YouTube, 9:16 for Reels, Shorts and TikTok, 1:1 for square) and press Create. Every project is saved as you go.
  3. Add an API key. Until there is one, the chat shows Add an API key to start editing. Press Open Settings and follow API keys; it takes about two minutes.
  4. Bring in your footage. Drag video, photo or music files onto the chat, or press + under the chat box. They are copied into the project.
  5. Ask for what you want. Type in the chat and press Enter. Be as specific as you like: "Make a 20 second vertical teaser from the best moments, with captions and upbeat music." See Editing by asking for ideas.
  6. Watch, adjust, export. Each step shows in the activity list and the preview updates as the AI works. Ask for changes ("make the title bigger"), undo anything with the arrows at the top, and press Export when you like it.

What is on the screen

PartWhat it does
Tabs, topEach open project has a tab, like a browser. The arrow button at the top left (or Ctrl+Shift+A) searches your tabs and recently closed projects, and opens Help and guides and Settings.
Left panelActivity shows every step as it happens; Review lists what could look better; Summary describes the edit; History lists every change.
MiddleThe live preview and the timeline strip. Click a clip on the timeline or a spot in the picture to point the AI at it.
RightThe chat: your requests, the AI's replies, and the model picker under the box.

Building it yourself

Most people should use the installers on the Download page. To run VideditBridge from its source code instead (to contribute, for example), you need Node.js 20 or newer, the .NET 10 SDK and Rust (for the fast parts of the editor; on Windows, with the Visual Studio C++ build tools).

git clone https://github.com/dev-henen/videditbridge
cd videditbridge
npm install
npm run native
dotnet run --project ui

The first start runs a short performance test to pick the fastest way to draw the preview on your computer.
