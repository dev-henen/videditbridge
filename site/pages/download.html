Install

Windows

  1. Run the setup file. It is the file you downloaded, VideditBridge-...-windows-x64-setup.exe.
  2. Get past the SmartScreen warning. If Windows says "Windows protected your PC", choose More info, then Run anyway. The app is not signed with a paid certificate yet, so Windows does not know it.
  3. Finish the setup. Then open VideditBridge from the Start menu.

macOS

  1. Copy it to Applications. Open the disk image, VideditBridge-...-macos-arm64.dmg, and drag VideditBridge onto Applications.
  2. Open it with a right-click the first time. In Applications, right-click VideditBridge and choose Open, then Open again. The app is not notarized by Apple yet, so a double-click alone is refused. If there is no Open button, go to System Settings, Privacy and Security, and press Open Anyway.
  3. Use it as usual. From then on it opens normally.

Linux

  1. Install VLC. It plays the video: on Debian and Ubuntu, sudo apt install vlc; on Fedora, sudo dnf install vlc.
  2. Make the file executable and run it. In a terminal, in the folder you downloaded it to:
chmod +x VideditBridge-*.AppImage
./VideditBridge-*.AppImage
